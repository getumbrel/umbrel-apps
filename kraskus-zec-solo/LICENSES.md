# Kraskus ZEC Solo Preview

Kraskus ZEC Solo is a Kraskus Crypto application.

This preview integrates the current development runtime with
5tratumOS for installation and user-interface qualification.

Runtime components include:

- Kraskus ZEC Solo application software
- Zebra, maintained by the Zcash Foundation
- nginx for the preview application proxy

The preview recipe is not the final production distribution.
